The World in One Day — 24 November 2026: a one-page newspaper front page
summing up Tuesday 24 November 2026 in a single 1024×1024 image. Jensen
Huang's comeback as Nvidia CEO leads the page — shares up more than 30%,
Nasdaq +6.5% — with five panels below: 24 dead in the Banten candy
factory fire, the Russian cargo ship Sparta II ablaze in the Gulf of
Finland, fresh strikes on Ukraine's Kyiv region, Lisbon marching over the
cost of living, and Alcaraz winning the ATP Finals. A footer strip carries
the day's smaller headlines. `main.py` (Python standard library only)
copies the shipped `entry.png` to the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
